# Speaker Notes

## Timing

| Phase | Time | Slides |
|---|---|---|
| Opening + Hook | 0-5 min | 1-2 |
| Startup Reality + Failure Modes | 5-15 min | 3-6 |
| Security as Enabler | 15-25 min | 7-8 |
| Technical Deep Dive | 25-40 min | 9-12 |
| Live Demo | 40-50 min | 13-15 |
| Anti-Patterns + Close | 50-60 min | 16-18 |

## Anchor Phrase

Repeat throughout: **"Security that enables speed"**

## Memorable Line

"AI didn't create new problems -- it amplified the ones we ignored."

## Delivery Tips

- Sound like you're explaining something real, not rehearsed
- Tie things back to actual production experience
- Avoid overloading YAML on slides
- Don't go too deep too early
- Let terminal output tell the story during the demo
- Pause after the secure test results -- let it sink in
